# ☕ Bean Boutique

### Coffee Shop Website | Academic Project

## 📖 About the Project

Bean Boutique is a coffee shop website I developed as an individual academic project during my NCC Level 4 Diploma in Computing at Strategy First College.

The website allows visitors to explore coffee products, browse brewing equipment, view upcoming events and special offers, and add products to a shopping cart.

Through this project, I gained practical experience in frontend web development using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling and layout
- **JavaScript** – Interactive features and shopping cart functionality
- **Local Storage** – Storing shopping cart data in the browser

## ✨ Key Features

- Coffee product and brewing equipment pages
- Shopping cart with quantity adjustment
- Events and workshops information
- Special offers and promotions
- Sign-in page interface
- Responsive website layout

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `beanboutique.html` in your web browser.

No additional installation is required.

## ⚠️ Known Limitations

- The shopping cart's remove button needs improvement.
- Some coffee product images do not display correctly in the cart.
