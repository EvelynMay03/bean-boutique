# ☕ Bean Boutique — Coffee Shop Website

## 📌 Project Overview

Bean Boutique is a multi-page coffee shop website developed as an individual academic project during my NCC Level 5 Diploma in Computing at Strategy First College.

The website provides an online platform where customers can explore coffee products, browse brewing equipment, discover coffee-related events, and view special offers.

This project helped me gain practical experience in frontend web development, responsive website design, and JavaScript-based user interactions.

## 🛠️ Technologies Used

- **HTML5** — Structures the website and its content.
- **CSS3** — Controls the website's appearance and layout.
- **JavaScript** — Implements interactive website functionality.
- **Local Storage** — Stores shopping cart information in the browser.

### Additional Libraries

The project also includes references to frontend libraries such as:

- Swiper.js
- SweetAlert2
- AOS (Animate On Scroll)
- Typed.js

## ✨ Features

### 🏠 Homepage
- Introduces Bean Boutique and its coffee-related offerings.
- Provides navigation to different sections of the website.

### ☕ Coffee Selection
- Displays a collection of coffee products.
- Provides product information and images.
- Includes options for adding products to the shopping cart.

### 🫖 Brewing Equipment
- Displays coffee brewing equipment.
- Allows visitors to explore available equipment.
- Includes shopping cart interactions.

### 🛒 Shopping Cart
- Allows users to add products to their cart.
- Supports increasing and decreasing product quantities.
- Calculates shopping cart totals.
- Uses browser Local Storage to maintain cart information.

### 📅 Events and Workshops
- Displays coffee-related events and workshops.
- Provides information about available activities.

### 🎁 Special Offers
- Presents promotional offers and subscription-related information.

### 👤 Sign-In Interface
- Provides a user sign-in page.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the downloaded ZIP file if necessary.
3. Open the project folder.
4. Locate `beanboutique.html`.
5. Open the file in a web browser such as Google Chrome.

The website can be viewed locally without installing a backend server.

Some interactive elements may require an internet connection to load external libraries.

## ⚠️ Known Limitations

The website was developed as an academic project and has some limitations:

- The shopping cart's product removal functionality requires improvement.
- Some Coffee Selection product images do not display correctly in the shopping cart.
- Some features may require further testing and refinement.
